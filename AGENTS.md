# Canonical research website

All future simulation changes belong in this website source tree. Preserve the
accepted `outputs/distributed_sector_lab_v3` archive. Keep all files on D:.

- Edit `src/` and `docs/`; `dist/` is generated by `npm run build`.
- Preserve `.openai/hosting.json` and its project_id. Reuse the same hosted Site.
- Keep the public interface and scientific figure labels in English.
- Run meaningful core tests after changing a plant, controller, packet protocol,
  or metric. Validate actual browser behavior before publication.
- Native input units differ by model. Never describe a normalized squared-input
  integral as physical energy across different robot models.
- Never clamp a robot endpoint or reset its velocity to fabricate feasibility.
- Distinguish mass-balancing energy, physical coverage cost, and kinetic storage.
  Do not turn a non-monotone recorded physical cost into a decreasing envelope.
- Latency clock values account for communication cost. Inertial plant equations
  use motion time; a delayed physical-plant experiment is a separate model.
- Never embed publishing credentials or access-control secrets in browser code.
- Public availability and developer permissions are distinct. Change the Site's
  audience only at the owner's request; do not add unrequested collaborators.
