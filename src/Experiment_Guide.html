What is each experiment testing?

The old atlas studies operators on masses and frequencies. The new runs add actual virtual boundaries, robot motion, local packet forwarding, and a separate carrier graph. Each question below identifies what a plot can establish.

Suggested reading: A01 -> A02 -> A04 -> A06 -> D01 -> D02 -> D03. The remaining figures deepen the arithmetic, spectrum, assignment, and communication analysis.

New distributed experiments

D01. Does a physical picture expose an algebraic blind residue?

Read the axes
Compare final robot paths and sector pictures above, then inspect the basic-mass pattern and the separate mass/load errors below.
Expected observation
After 50 -> 49 at k=7, single-order service loads balance but basic mass error plateaus at sqrt(6)/50. Control orders 7+8 remove the plateau.
Scope of this test
Paths are sampled actual simulated motion. The annulus controller is feasible polar motion; pairwise robot collision avoidance is not implemented.

D02. Does changing the carrier necessarily change the control operator?

Read the axes
Top: carrier edges at final positions. Bottom left: error against motion time. Bottom right: error against elapsed time including reliable routing rounds.
Expected observation
The ring/path pair has identical mass updates and different routing cost. Compare the clocks to understand the delay introduced by communication.
Scope of this test
A connected frozen carrier delivers a full snapshot. This does not test asynchronous control with packet loss.

D03. What physical meaning does k have in a symmetric domain?

Read the axes
Each panel has N=60 and identical uniform basic masses, but a different service order k. Robot targets follow the analytical centroid-radius formula.
Expected observation
Increasing k moves the target ring inward. At k=N every robot is assigned the whole disk and all targets coincide at the origin.
Scope of this test
Higher order means overlapping responsibility. It does not automatically mean collision avoidance or distinct sensor footprints.

D04. What is paid for complementary control and changing radio links?

Read the axes
Read mass-error decay, packet/byte cost, moving carrier edge revisions, and the independent minimum-mass/domain-margin diagnostics.
Expected observation
Simultaneous and switching helpers repair the blind residue. The radio graph changes at fixed N,k. Order 1 is also valid but slower in this horizon.
Scope of this test
Byte costs use an assumed packet model. Positive atoms and domain margins are not pairwise separation certificates.

D05. Can robot rearrangement change routing without changing the quotient?

Read the axes
Compare original-ID carrier links, the coincident mass-error curves, and the accumulated byte-hop cost after a role transfer.
Expected observation
A row permutation leaves the mass spectrum unchanged. It can make the logical overlay much more expensive on a fixed carrier.
Scope of this test
The deterministic angle-ranked assignment does not optimize cyclic phase, distance, energy, or collision-free motion.

D06. Which geometry and demand map are the robots using?

Read the axes
Left: the analytic annular demand density in physical coordinates. Right: normalized angular demand w(theta).
Expected observation
Equal angular widths generally do not give equal mass. The cumulative coordinate x=F(theta) makes positive mass updates realizable as ordered ray motion.
Scope of this test
This is one shared known map. Private maps, unknown demand estimation, and limited sensing are not implemented.

D07. Can failure position matter even with the same N and gcd?

Read the axes
Columns remove original robot IDs 1,13,37 from equal N=50 masses. Top: final basic masses. Bottom: phases at blind Fourier labels of N=49,k=7.
Expected observation
All have the same blind-error magnitude, but the elevated residue class and Fourier phases change with failure position.
Scope of this test
Equal magnitudes here follow rotational symmetry in mass coordinates. Nonuniform pre-failure masses or communication/geometry can break that equality.

Expected observation
Look for discontinuous arithmetic stripes. At fixed k=21, the gcd pattern repeats every 21 counts; full spectra and state dimensions do not repeat.

A03. Does the same gcd mean exactly the same dynamics?

Read the axes
At fixed N=1000, compare labelled frequency j, sorted eigenvalue index, responsibility response, and the slowest labelled frequency.
Expected observation
Unit steps are isospectral for Q, but their eigenvalue labels and responsibility responses differ. For k=21 the slow label includes j=381.
Scope of this test
An unordered spectrum does not determine robot-ID routing cost or which spatial perturbation decays slowly.

A04. What can balanced service loads fail to reveal?

Read the axes
Rows use N=1000,999,994,987 and k=21. Left: blind Fourier indicators. Right: normalized limiting basic masses for the first 84 indices.
Expected observation
The limiting masses repeat with period d. N=1000 gives a constant; N=999 gives a three-period pattern. Every row has equal service loads.
Scope of this test
This is the cleanest picture of the nonunique partition family. The masses are synthetic, not measured robot positions.

A05. Which gcd classes occur, and how many orders belong to each?

Class size is a count of integer parameters, not a probability unless an order-sampling rule is specified.

A06. How do several orders remove different blind directions?

A07. Can a tiny auxiliary weight repair a blind mode quickly?

Read the axes
At N=999, vary the weight alpha on order 22 beside order 21. Read the minimum mean-zero eigenvalue, the active worst frequency, one old blind eigenvalue, and its decay.
Expected observation
The old blind eigenvalue opens as 3 alpha, but a very small alpha gives slow recovery. The best weight is set by competing bottleneck modes.
Scope of this test
Here mode switching means a change of the worst spectral frequency as a weight varies; it is not a robot failure or a temporal switching experiment.

A08. What changes when the coefficient domain changes?

Read the axes
The panels show cyclotomic blocks at N=987,k=21, their rational dimensions, ranks over finite fields, and the integer torsion order s=k/d.
Expected observation
The 20 real blind dimensions split into rational blocks of dimensions 2, 6, and 12. Finite-field nullity can differ from real nullity.
Scope of this test
Robot masses are real-valued here. Finite-field rank and integer torsion are structural extensions, not new physical blind directions in this controller.

A10. How is a random initial condition distributed over the blind family?

Read the axes
For each N, positive initial masses are sampled uniformly on the simplex. Top: limiting relative mass-error density. Bottom: covariance eigenvalues.
Expected observation
There are d-1 nonzero covariance directions. The theoretical mean squared error is (d-1)/(N+1) for the chosen Dirichlet(1) model.
Scope of this test
This is a specified sampling distribution. It is not an empirical distribution of sensor noise, robot faults, or all possible partitions.

A11. Does complementarity give a rate independent of N?

Read the axes
N=21a+1 grows. Left: mean-zero spectral gap on log axes. Right: N squared times the gap. Compare order 21 with equally weighted 21 and 22.
Expected observation
Both eventually scale as N^-2 for these bounded orders. Complementarity improves the constant and removes blind modes; it does not create a uniform expander gap.
Scope of this test
Rates use normalized logical-control gain. Communication cost and finite radio range are absent from this algebra-only comparison.

A12. What does the staged removal of blind modes look like?

Read the axes
At N=1008, successive control sets are [21], [21,14], [21,14,6]. Panels show mass over index/time, total error, and selected Fourier amplitudes.
Expected observation
The state first approaches a 21-period pattern, then a 7-period pattern, then a constant. Selected frequencies disappear at different stages.

A13. Why does a gcd count blind frequencies?

Read the axes
The drawings compare roots of unity for N and k on the complex unit circle. Common roots are intersections.
Expected observation
There are d common roots, but the root 1 is not a responsibility zero because R(1)=k. Thus the blind count is d-1.
Scope of this test
The unit circle is frequency space, not the physical annulus or robot arrangement.

Image: 13_universal_frequency_circle.png

A14. What is gained by averaging symmetry classes of jumps?

Read the axes
Left: relations gcd(i-j,60). Center: the divisor-indexed Ramanujan eigenmatrix for N=1000. Right: normalized gaps for one order, two orders, and all unit steps.
Expected observation
Symmetry compresses the calculations. Averaging all unit steps has a much larger gap at this N, while using 400 distinct neighbors.
Scope of this test
The larger degree is a real cost. This is not evidence that a bounded-budget local radio network has the same rate.

A15. Can growing orders alter the effective graph dimension?

Read the axes
Take N=L^2+1. Compare a single growing step, bounded steps 21/22, and adaptive steps 1/L. The right panel counts reachable vertices within graph radius R.
Expected observation
The adaptive pair has a gap of order N^-1 and locally quadratic ball growth, rather than the linear growth of a single step. The gap still tends to zero.
Scope of this test
Graph radius counts logical hops. Long physical links, moment-acquisition cost, and actual radio reachability must be budgeted separately.
